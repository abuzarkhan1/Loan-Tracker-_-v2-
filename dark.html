Code & API

Developer trust is built through transparency. Every feature is paired with clean, copy-ready code examples.

Create a Payment Intent
Initiate a payment flow with a single API call. The returned client_secret is used to confirm the payment on the client side.
Node.js cURL Python 
const prismatic = require('prismatic')('sk_test_...');

const intent = await prismatic.paymentIntents.create({
  // Amount in cents
  amount: 2000,
  currency: 'usd',
  // Customer ID from previous step
  customer: 'cus_9s6XK...',
  // Automatic confirmation
  confirm: true,
});
Webhook Handler
Verify webhook signatures to ensure events are sent by Prismatic. Never trust unverified payloads.
Express Fastify 
app.post('/webhook', async (req, res) => {
  const sig = req.headers['prismatic-signature'];
  const event = prismatic.webhooks.constructEvent(
    req.body,
    sig,
    webhookSecret
  );

  if (event.type === 'payment.succeeded') {
    await fulfillOrder(event.data.object);
  }

  res.json({ received: true });
});
